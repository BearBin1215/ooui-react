# Component overview

This library reimplements OOUI in React. Components follow the original class hierarchy and fall into four families — **widgets, layouts, dialogs and toolbars** — 60 in total.

Components **ship no styles**: they only output DOM and `oo-ui-*` class names identical to the original. Load the OOUI stylesheets first, as described in [Usage](../guide/usage.mdx); the props shared by every component are covered in [Common props](../guide/basics.mdx).

- [PopupButton](./popup-button/index.mdx) a button that opens a popup on click
