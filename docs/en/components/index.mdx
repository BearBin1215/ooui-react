# Component overview

This library reimplements OOUI in React. Components follow the original class hierarchy and fall into four families — **widgets, layouts, dialogs and toolbars** — 60 in total.

Components **ship no styles**: they only output DOM and `oo-ui-*` class names identical to the original. Load the OOUI stylesheets first, as described in [Usage](/en/guide/usage.html); the props shared by every component are covered in [Common props](/en/guide/basics.html).

## Widgets

- [Button](/en/components/button/index.html) icons, indicators, labels and link forms

- [ToggleSwitch](/en/components/toggle-switch/index.html) switch
- [ButtonGroup](/en/components/button-group/index.html) groups several buttons; can be disabled as a whole
- [PopupButton](/en/components/popup-button/index.html) a button that opens a popup on click
- [Popup](/en/components/popup/index.html) the popup layer itself
- [Label](/en/components/label/index.html) standalone text label

- [ProgressBar](/en/components/progress-bar/index.html) progress bar
- [Message](/en/components/message/index.html) inline message notice (with a close button)

</div>

### Form submission

A set of field widgets that submit natively with a `<form>`, used together with `FormLayout`.

<div className="doc-component-grid">

- [ButtonInput](/en/components/button-input/index.html) submit button
- [DropdownInput](/en/components/dropdown-input/index.html) dropdown select field
- [CheckboxMultiselectInput](/en/components/checkbox-multiselect-input/index.html) checkbox group field
- [RadioSelectInput](/en/components/radio-select-input/index.html) radio group field
- [HiddenInputWidget](/en/components/hidden-input-widget/index.html) a field submitted with the form but never shown

</div>
