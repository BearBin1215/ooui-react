## Why this library?

Back in 2023, while writing [my own Moegirlpedia gadget](https://github.com/BearBin1215/MoegirlPedia), I found that keeping state in a loop with jQuery alone was painful in more complex scenarios, so I wanted to bring in a modern framework. At the time:

- MediaWiki was on 1.31, which shipped neither Vue nor Codex.
- Bundling Vue myself started at 60 KB, and writing a little more would push the bundle past what could be uploaded to the site without timing out.
- Most mature component libraries ship their own stylesheets, which also makes for large bundles.
- I lack the art skills to design the styles myself ~~(important!)~~.

So I went with [Preact](https://preactjs.com/) plus a self-built OOUI component library: a small framework, no stylesheet, rendering only DOM.

As AI-assisted programming took off, this project grew into a proper component library. Moegirlpedia has since upgraded MediaWiki and supports Vue + Codex, but I still think this library earns its place.
