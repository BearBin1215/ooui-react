# MenuTagMultiselect 菜单标签输入

> [源代码](https://github.com/BearBin1215/ooui-react/tree/main/src/widgets/MenuTagMultiselect) | [原版组件](https://doc.wikimedia.org/oojs-ui/master/js/OO.ui.MenuTagMultiselectWidget.html "OO.ui.MenuTagMultiselectWidget")

带候选菜单的标签输入，属性与 [TagMultiselect](../tag-multiselect/index.mdx) 一致，另增必填的 `options`。

## 基本用法

输入即过滤候选，↑↓ 在候选间移动高亮，Enter 选定高亮项（无高亮时提交输入文本）；未开启 `allowArbitrary` 时，输入文本不在候选值域内会被拒绝（不报错，但不生成标签），需要自由输入见下节。候选自身的 `disabled` 表示禁用项——不可添加为标签。

```tsx preview
import { useState } from "react";
import { MenuTagMultiselect } from "ooui-react";

const options = [
  { value: "bold", label: "加粗", icon: "bold" },
  { value: "italic", label: "斜体", icon: "italic" },
  { value: "link", label: "链接", icon: "link" },
  { value: "image", label: "图片", icon: "image" },
];

function App() {
  const [tags, setTags] = useState<(string | number)[]>(["bold"]);

  return (
    <div style={{ display: "flex", flexDirection: "column", gap: 8, maxWidth: 360 }}>
      <MenuTagMultiselect
        options={options}
        value={tags}
        onChange={setTags}
        placeholder="输入以过滤，或从菜单挑选"
      />
      <div>已选：{tags.join("、") || "（空）"}</div>
    </div>
  );
}

export default App;
```

## 切换语义与标签编辑

菜单候选是**切换语义**：对已选中的候选再次 Enter / 点击会**移除**对应标签——同一候选既是添加入口也是移除入口，已添加标签对应的菜单项呈选中态（键入添加的标签同样同步选中态）。{/* deviations: dev-tag-typed-menu-selected */}

点击标签的行为随 `allowArbitrary` 分叉：未开启时点击标签是在菜单中定位（打开菜单并高亮对应候选），[TagMultiselect](../tag-multiselect/index.mdx) 的 `allowEditTags` 回填编辑不生效；开启 `allowArbitrary` 后点击标签才把标签文本移回输入框编辑。

:::note 与原版的差异
`inputPosition='none'`（无输入框）形态下点击标签同样能展开菜单并高亮被点项——原版该形态没有任何展开菜单的路径；展开后暂无键盘导航。{/* deviations: dev-menu-open-no-input */}
:::

## 值域与任意值

未开启 `allowArbitrary` 时，标签的合法值域是 `allowedValues` 与 `options` 各项 `value` 的并集——通常只给 `options`，即只能添加候选里的值。开启 `allowArbitrary` 后，还可输入候选之外的自由文本作为标签。`clearInputOnChoose`（默认开）决定选定菜单项后是否清空输入框里的过滤文本。

```tsx preview
import { useState } from "react";
import { MenuTagMultiselect } from "ooui-react";

function App() {
  const [tags, setTags] = useState<(string | number)[]>([]);

  return (
    <div style={{ maxWidth: 360 }}>
      <MenuTagMultiselect
        allowArbitrary
        options={[
          { value: "cat", label: "猫" },
          { value: "dog", label: "狗" },
        ]}
        value={tags}
        onChange={setTags}
        placeholder="可从候选选，也可自由输入回车添加"
      />
    </div>
  );
}

export default App;
```

## 富内容标签

选项 `label` 收 `ReactNode`；当它是富内容（非纯字符串）时，前缀过滤与回填需要的纯文本要经 `labelText` 显式给出，否则该选项不参与前缀过滤（详见[选择与选项 · 标签多选的选项](../../guide/options.mdx#标签多选的选项)）。`fixed: true` 的标签固定、不可移除。

```tsx preview
import { useState } from "react";
import { MenuTagMultiselect } from "ooui-react";

function App() {
  const [tags, setTags] = useState<(string | number)[]>(["template"]);

  return (
    <div style={{ maxWidth: 320 }}>
      <MenuTagMultiselect
        value={tags}
        onChange={setTags}
        placeholder="试试输入「重」按前缀过滤"
        options={[
          {
            value: "template",
            label: (
              <>
                <b>模板</b>（常规页面）
              </>
            ),
            labelText: "模板",
            fixed: true,
          },
          {
            value: "redirect",
            label: (
              <>
                <b>重定向</b>（指向其他页面）
              </>
            ),
            labelText: "重定向",
          },
        ]}
      />
    </div>
  );
}

export default App;
```

标签「模板」来自 `fixed: true` 的候选，带固定标记（无关闭按钮）；键入「重」能按 `labelText` 过滤到「重定向」候选并回填纯文本。

## API

在 [TagMultiselect](../tag-multiselect/index.mdx) 全部属性之上：

| 属性 | 描述 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `options` | 候选菜单选项集（**必填**），字段见[选择与选项](../../guide/options.mdx#标签多选的选项) | `MenuTagMultiselectOptionProps[]` | — |
| `clearInputOnChoose` | 选定菜单项后是否清空过滤文本 | `boolean` | `true` |
