# 组件总览

本组件库以 React 重实现 OOUI，组件按原版类层级分为**控件、布局、弹窗、工具栏**四族，合计 60 个。

组件**不自带样式**，只输出与原版一致的 DOM 与 `oo-ui-*` 类名，使用前请先按[使用方式](/guide/usage.html)引入 OOUI 样式表；所有组件共有的属性规则见[通用属性与 ref](/guide/basics.html)。

## 控件

<div className="doc-component-grid">

- [Button](/components/button/index.html) 支持图标、指示器、标签与链接形态
- [ToggleButton](/components/toggle-button/index.html) 可切换的按钮（按下/弹起）
- [ToggleSwitch](/components/toggle-switch/index.html) 开关
- [ButtonGroup](/components/button-group/index.html) 把若干按钮排成一组，可统一禁用
- [PopupButton](/components/popup-button/index.html) 点击弹出浮层的按钮
- [Popup](/components/popup/index.html) 弹出浮层本身
- [Label](/components/label/index.html) 独立文本标签
- [Icon](/components/icon/index.html) 图标
- [Indicator](/components/indicator/index.html) 指示器（“展开”“必填”一类标记）
- [ProgressBar](/components/progress-bar/index.html) 进度条
- [Message](/components/message/index.html) 行内消息提示（含关闭按钮）

</div>
