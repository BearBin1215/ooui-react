# 组件总览

本组件库以 React 重实现 OOUI，组件按原版类层级分为**控件、布局、弹窗、工具栏**四族，合计 60 个。

组件**不自带样式**，只输出与原版一致的 DOM 与 `oo-ui-*` 类名，使用前请先按[使用方式](../guide/usage.mdx)引入 OOUI 样式表；所有组件共有的属性规则见[通用属性与 ref](../guide/basics.mdx)。

## 控件

<div className="doc-component-grid">

- [Button](./button/index.mdx) 支持图标、指示器、标签与链接形态
- [ToggleButton](./toggle-button/index.mdx) 可切换的按钮（按下/弹起）
- [ToggleSwitch](./toggle-switch/index.mdx) 开关
- [ButtonGroup](./button-group/index.mdx) 把若干按钮排成一组，可统一禁用
- [PopupButton](./popup-button/index.mdx) 点击弹出浮层的按钮
- [Popup](./popup/index.mdx) 弹出浮层本身
- [Label](./label/index.mdx) 独立文本标签
- [Icon](./icon/index.mdx) 图标
- [Indicator](./indicator/index.mdx) 指示器（“展开”“必填”一类标记）
- [ProgressBar](./progress-bar/index.mdx) 进度条
- [Message](./message/index.mdx) 行内消息提示（含关闭按钮）
