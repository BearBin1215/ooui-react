# PopupButton 浮层按钮

> [源代码](https://github.com/BearBin1215/ooui-react/tree/main/src/widgets/PopupButton) | [原版组件](https://doc.wikimedia.org/oojs-ui/master/js/OO.ui.PopupButtonWidget.html "OO.ui.PopupButtonWidget")

弹出按钮：点击 [Button](/components/button/index.html) 开合一个锚定到它的 [Popup](/components/popup/index.html)，并内建“点按钮与浮层之外自动关闭”。多数“点按钮弹一块浮层”的场景用它即可，无需手写 Popup 的锚定与开合。

## 基本用法

```tsx preview
import { PopupButton } from "ooui-react";

function App() {
  return (
    <div style={{ padding: 40 }}>
      <PopupButton
        icon="language"
        defaultOpen
        popupContent={
          <div style={{ padding: 12 }}>浮层里可以放任意内容，比如一段说明或一组控件。</div>
        }
      >
        选项
      </PopupButton>
    </div>
  );
}

export default App;
```

## 受控开合

需要在外侧控制显隐时用 `open` / `onOpenChange`；点按钮、点外部、关闭按钮、Escape 都会回调 `onOpenChange`。

```tsx preview
import { useState } from "react";
import { PopupButton } from "ooui-react";

function App() {
  const [open, setOpen] = useState(false);

  return (
    <div style={{ display: "flex", alignItems: "center", gap: 12, padding: 40 }}>
      <PopupButton
        open={open}
        onOpenChange={setOpen}
        head
        label="颜色"
        padded
        popupContent={<div style={{ padding: 12 }}>头部带标题与关闭按钮的浮层。</div>}
      >
        选颜色
      </PopupButton>
      <span>当前 open：{String(open)}</span>
    </div>
  );
}

export default App;
```

## 浮层定位

`position` / `align` / `anchor` / `autoFlip` / `width` / `height` / `padded` / `head` / `footer` / `container` 等浮层属性都会透传给内部 Popup（含义同 [Popup](/components/popup/index.html)）。缺省以按钮为锚点、朝下弹出。

## API

| 属性 | 描述 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `children` | 按钮标签 | `ReactNode` | — |
| `popupContent` | 浮层内容 | `ReactNode` | — |
| `open` | 浮层是否打开（受控） | `boolean` | — |
| `defaultOpen` | 非受控初始打开态 | `boolean` | `false` |
| `onOpenChange` | 开合变化回调（点按钮 / 点外部 / 关闭按钮 / Escape） | `(open: boolean) => void` | — |
| `onClick` | 按钮点击回调（在切换开合前触发） | `(ev: ButtonClickEvent) => void` | — |
| `label` | 浮层头部标签，经 `head` 渲染（按钮标签是 `children`，二者分离） | `ReactNode` | — |
| `icon` / `flags` / `framed` / `title` / `accessKey` / `invisibleLabel` / `disabled` | 按钮侧属性，含义同 [Button](/components/button/index.html) | — | — |
| `position` / `align` / `anchor` / `autoFlip` / `head` / `hideCloseButton` / `padded` / `width` / `height` / `footer` / `container` / `hideWhenOutOfView` / `containerPadding` | 浮层侧属性，透传给内部 [Popup](/components/popup/index.html) | — | — |

`framed` 除决定按钮边框外，还会切换浮层的带框 / 无框外观。`label` 路由到浮层头部，`invisibleLabel` 仅作用于按钮侧——原版 `PopupButtonWidget` 中两者属于按钮、popup 经独立配置传入。`active`、`autoClose`、`autoCloseIgnore` 由组件内部管理，不接受外部覆盖。
