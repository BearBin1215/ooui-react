## 为什么会有这个组件库？

2023年，我在编写[自己的萌娘百科小工具](https://github.com/BearBin1215/MoegirlPedia)时，有些较复杂的场景仅靠 JQuery 想要实现状态闭环十分费劲，就想引入一个现代的框架。当时情况是这样：

- MediaWiki 版本为1.31，没有自带 Vue、Codex。
- 如果自行打包完整的 Vue，构建产物从 60KB 起步，稍微多写一点就会导致产物太大、提交到站内超时。
- 成熟的组件库多数会引入样式表，产物同样很大。
- 我美术水平太差不会设计样式~~（重要！）~~。

因此，我选择了 [Preact](https://preactjs.com/) 结合自建 OOUI 组件库的方案，框架体积小、无样式表，只需要渲染 DOM。

随着 AI 编程的兴起，本工程得以较为系统化地开发成一个完整的组件库。虽然如今萌百已经升级了 MediaWiki 版本并且支持了 Vue + Codex 的方案，但我觉得这个组件库应当还是有其意义的。
